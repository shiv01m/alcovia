## What's where

| Folder | Contents |
|---|---|
| `schema/` | Postgres (Supabase) table definitions for GTM and student tracking |
| `sql/` | One query per metric in the brief, plus the daily views the dashboards read |
| `data/` | Dummy data as CSV |
| `scripts/` | Data generators, a runner that tests every SQL query, and the dashboard data export |
| `dashboards/` | The two dashboards (static HTML + Chart.js) |
| `n8n/` | 5 exported n8n workflows: ClickUp lead stages, Razorpay payments, daily Meta Ads pull, 8 pm quiz scores, nightly student alerts |

The n8n workflows are exported designs. They need Alcovia's ClickUp, Razorpay, Meta, WhatsApp and database credentials before they can run, so they have not been run against live accounts.

## How data flows (target state)

```
Meta Ads API ─┐
Razorpay ─────┤                ┌─> GTM tracker
ClickUp ──────┼─> n8n ─> Postgres views ─┤
App events ───┤                └─> Student dashboard ─> weekly advisor review
Wearables ────┘
```

ClickUp stays the place where the team works. n8n copies every status change into the database, so the dashboards never depend on someone updating a sheet.

## Run it locally

```bash
pip install duckdb
python scripts/generate_gtm_dummy_data.py   # writes data/gtm/*.csv
python scripts/run_gtm_metrics.py           # runs every query in sql/gtm_metrics.sql
python scripts/export_dashboard_data.py     # rebuilds dashboards/gtm/data.js
python scripts/generate_student_dummy_data.py  # student CSVs + dashboards/students/data.js
python scripts/build_pages.py               # full HTML pages for GitHub Pages
```
